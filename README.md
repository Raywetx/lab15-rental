# Система аренды транспортных средств (Лабораторная №15)

## Назначение
Консольное приложение для учета автомобилей и мотоциклов и оформления их аренды.

## Реализованные возможности
- Добавление/удаление транспорта.
- Поиск доступного транспорта.
- Оформление аренды и возврат.
- Расчёт стоимости (мотоциклы со скидкой 20%).
- Сохранение и загрузка данных из файла.

## Инструкция по запуску
1. Убедитесь, что установлена Java (JDK 17+).
2. Скомпилируйте файл `Main.java`.
3. Запустите класс `Main`.

## Архитектура
- `Vehicle` — абстрактный класс.
- `Car` и `Motorcycle` — наследники.
- `RentalService` — бизнес-логика.
- `GenericRepository<T>` — обобщенное хранилище.
- `VehicleUnavailableException` — собственное исключение.
